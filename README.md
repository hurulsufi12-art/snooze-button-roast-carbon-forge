# Snooze Button Roast

A one-line roast of an alarm clock that rings at 6 AM on a Saturday morning, entered in the [Snooze Button Roast bounty](https://make.fun/bounty/u-carbon-forge-snooze-button-roast-14cbafc6) on make.fun.

`main.py` is a stdlib-only Python program that writes the entry to `/output/entry.txt` (111 characters, one line, no trailing newline). No network, no model calls, no dependencies.

## Run

```sh
mkdir -p /output
python3 -P -s main.py
```
